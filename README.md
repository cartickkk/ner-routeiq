# NER-RouteIQ: AI-Based Smart Logistics and Accessibility Intelligence Platform for NER
**Smart India Hackathon 2026 | Problem ID: SIH26002**

## 🚀 Overview
NER-RouteIQ is an intelligent, weather-aware supply chain logistics and hazard prediction platform tailored specifically for the challenging terrains of the North Eastern Region (NER).

## 🛠️ Tech Stack
* **Frontend:** HTML5, JavaScript (ES6), Tailwind CSS, Leaflet.js
* **Backend & Database:** Supabase (PostgreSQL + PostGIS)
* **Automation & Alerts:** Make.com webhooks (Telegram & Gmail integration)
* **Hosting:** Netlify

## ⚙️ Core Architecture & Features
1. Interactive Mapping & GPS Tracking
2. AI Risk Prediction Engine
3. Automated Hazard Alerts (Make.com)
4. Zero-Downtime Resilience Engine (`seed.py`)
5. Voice Assistance (Web Speech API)
